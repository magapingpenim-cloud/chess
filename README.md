# ♞ ChessUp — шахматный Mini App в Telegram · @chessUpper_bot

Пользователь жмёт «Старт» (или кнопку «Играть» у поля ввода) — внутри Telegram открывается приложение с доской. Всё происходит там.

## Что внутри приложения
- **Выбор уровня** при первом входе (600 / 1000 / 1400 / 1800).
- **Доска**: ходы касанием, точки доступных ходов, подсветка последнего хода и шаха, вибрация на верный/неверный ход, анимация ответа соперника.
- Проверка ходов и рейтинг — **на сервере** (решение не видно в приложении, накрутить нельзя).
- **Главная**: рейтинг, серия дней 🔥, решено, точность, место в топе, остаток бесплатных задач.
- 📅 Задача дня · 🎯 Тренировка по темам (VIP) · 🏆 Топ-20 · 🎁 «Пригласить друга» (шеринг ссылки `startapp=ref_…`).
- **VIP прямо в приложении**: оплата Telegram Stars во всплывающем окне, без выхода из приложения.
- Незаконченная задача сохраняется — «Продолжить задачу».
- Подстраивается под светлую/тёмную тему Telegram.

### 📈 Рейтинг
Чем выше уровень игрока, тем меньше плюс за победу и тем больше минус за поражение (в задачах и онлайн-партиях). Против равного соперника:

| Рейтинг | Победа | Поражение |
|---|---|---|
| 600 | +22 | −10 |
| 1000 | +19 | −13 |
| 1400 | +16 | −16 |
| 1800 | +13 | −19 |
| 2400 | +8 | −24 |

Одна ошибка в задаче штрафуется мягко (около −1…−2), подсказка или 2+ ошибки — заметнее, сдача — полностью.

### ⚔️ Партии
- **С тренером-ботом** — 5 тренеров (Пешкин ≈600 → Ферзева ≈2300), движок Stockfish работает прямо в телефоне игрока (сервер не нагружается). Тренер:
  - 💡 подсказывает лучший ход (бесплатно 2 за партию, в VIP — безлимит);
  - 😬 ловит зевки: «Кf3 — неточность. Лучше было Сc4» с кнопкой **«Переходить»**;
  - ↩️ разрешает вернуть ход; после победы предлагает тренера посильнее.
- **Онлайн с живыми игроками** — 3, 3+2, 5 и 10 минут, часы, ходы проверяет сервер, отдельный рейтинг партий (Эло).
  Если за **20 секунд** соперник не найден — автоматически начинается партия с тренером-ботом подходящего уровня (он честно подписан как бот).
  Онлайн-партии хранятся в памяти процесса — на Amvera должна быть **1 реплика** (так по умолчанию).

**Бот** только открывает приложение, принимает оплату, шлёт утреннюю «задачу дня», команды `/cancel_sub`, `/terms`, `/paysupport`, админские `/stats`, `/refund`.

## Запуск локально (для разработки)
```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
set DEV_MODE=1
.venv\Scripts\python bot.py
```
Откройте http://localhost:8080 — приложение работает в браузере без Telegram (тестовый пользователь).

## Деплой на Amvera (рекомендуется)
Конфиг уже готов: `amvera.yml` (Python 3.12, `bot.py`, постоянное хранилище `/data`, порт 8080). Файлы для загрузки собраны в папке `amvera_upload` (9 файлов, без секретов).
1. amvera.ru → создать проект «Приложение», имя латиницей (например `chessup`).
2. Вкладка «Репозиторий» → перетащить все файлы из `amvera_upload`.
3. Вкладка «Домены» → «Бесплатный домен Амвера», тип HTTPS → скопировать адрес.
4. Вкладка «Переменные»: `BOT_TOKEN` (**как секрет**), `WEBAPP_URL` = адрес из шага 3, `ADMIN_IDS`, `SUPPORT_CONTACT`.
5. Остановить локальную копию бота (два бота с одним токеном конфликтуют), затем собрать/перезапустить проект.
6. В логах: «Загружаю базу задач Lichess…» → через несколько минут «База Lichess загружена». База и пользователи хранятся в `/data/chessbot.db` и переживают пересборки.
7. BotFather → Bot Settings → Configure Mini App → тот же адрес.
Если в логах ошибки соединения с `api.telegram.org` — выберите другой регион проекта или напишите в поддержку Amvera.

## Запуск на своём сервере
Telegram открывает Mini App **только по HTTPS-адресу**. Варианты:
1. **VPS + домен (рекомендую)**: сервер ~300–500 ₽/мес + домен ~200 ₽/год. Caddy автоматически выдаёт HTTPS:
   ```
   chessup.example.ru {
       reverse_proxy localhost:8080
   }
   ```
2. **Временно с этого ПК** — HTTPS-туннель (адрес меняется при перезапуске, ПК должен быть включён).

Затем в `.env`: `WEBAPP_URL=https://ваш-адрес` и перезапуск. Бот сам поставит кнопку «Играть» и описание.
В @BotFather → `/mybots` → Bot Settings → Configure Mini App → укажите тот же URL — появится кнопка «Открыть» в профиле бота и ссылки `t.me/chessUpper_bot?startapp`.

## Отслеживание источников рекламы
Для каждого рекламного сервиса — своя ссылка. Источник записывается при первом входе пользователя.
- `/link adsgram` — бот пришлёт ссылки `t.me/chessUpper_bot?startapp=src_adsgram` (сразу в приложение) и `?start=src_adsgram` (через бота).
- `/sources` — воронка по каждому источнику: пришли → решали задачи → вернулись во 2-й день → заплатили → сколько ⭐.
- `/sources 7` — только пользователи, пришедшие за последние 7 дней.

Без метки — `organic`, по реферальным ссылкам друзей — `ref`. Сравнивайте сервисы по звёздам на потраченный рубль, а не по числу пришедших.
